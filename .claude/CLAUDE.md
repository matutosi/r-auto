# r-auto プロジェクト

書籍『Rによる自動化・効率化レシピ集』(松村俊和，2025，森北出版) の**サポートページ**．
本文のコードとデータを配布する．原稿は [rauto](../rauto)．

- 出版社のページ: <https://www.morikita.co.jp/books/mid/085831>
- 正誤表: <https://www.morikita.co.jp/exclusive/download/3152>
- コード: <https://github.com/matutosi/r-auto/tree/main/R/>

## 主なファイル

- `R/` … 本文のコード
  - `01_01_CODE-NAME.R` … コード番号別のファイル
  - `01_00_CHAPTER.R` … 章ごとにまとめたファイル
  - `02_00_CHAPTER_funs.R` … 章内の全関数
- `data/` … 本文で使うデータ (43 ファイル)
- `README.md` … 導入・ダウンロード方法・正誤表・関連記事
- `r-auto.jpg` … 書影

## 決めごと

- **正誤表に載った修正は `R/` のコードへ反映済みにしておく** (README にそう書いてある)．
- 読者が R から直接ダウンロードして使えるよう，README のダウンロード用コードを動く状態に保つ．
- コードの本体は原稿 ([rauto](../rauto)) 側にあるので，**原稿を直したらこちらへ反映する**
  (逆向きに直さない)．
